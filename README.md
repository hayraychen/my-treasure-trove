- **AI 资讯**：来自下方列出的公开 RSS 源；链接直达原文。显示 RSS 提供的发布时间，若源未提供则明确标为未知。

- “热门”是**最近 30 天有推送的搜索结果中按 Stars 排序**，不是 GitHub 官方 Trending 榜单，也不代表质量背书。
- 所有时间均为 UTC。抓取时间与源提供的发布时间分开标注；数据源或 API 失败时会显示错误，不会伪装成完整更新。
